# RETRO OS

HTML/CSS/Vanilla JavaScript로 만든 브라우저용 가상 데스크톱입니다. 부팅 후 가운데 로딩 창과 픽셀 고양이가 나타나며, 아이콘 또는 시작 메뉴에서 프로그램을 실행합니다. 백엔드·계정·API 키·외부 API·CDN이 필요하지 않습니다.

## 실행

프로젝트 폴더에서 Python 3으로 정적 서버를 실행합니다. 빌드나 npm 패키지 설치는 필요하지 않습니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173/`을 엽니다. ES Modules를 사용하므로 `index.html`을 `file://`로 직접 열지 마세요. 필요한 파일이 로컬 정적 서버에서 제공되면 외부 인터넷 연결 없이 사용할 수 있습니다. 서비스 워커는 사용하지 않습니다.

## 프로그램

| 프로그램 | 기능 |
| --- | --- |
| 내 컴퓨터·내 문서·휴지통 | 중첩 폴더, 뒤로·앞으로·상위 이동, 주소 입력, 새 폴더·문서, 이름 변경·이동·삭제·복원·영구 삭제 |
| 메모장 | 새 문서·열기·저장·다른 이름으로 저장, 텍스트 다운로드, 실행 취소·다시 실행, 미저장 경고 |
| 그림판 | 브러시·지우개·직선·사각형, 색상·굵기, 최근 8회 실행 취소, 새 그림 확인, PNG 다운로드 |
| 명령 프롬프트 | `help`, `date`, `time`, `dir`/`ls`, `cd`, `cat`/`type`, `clear`, `echo`, `theme`, `about`, `exit` |
| 지뢰찾기 | 9×9·지뢰 10개, 첫 클릭 안전, 연쇄 열기, 깃발, 승리·실패·재시작 |
| 설정 | 클래식·미드나이트·올리브, 배경색·아이콘 크기, 애니메이션·음소거 설정, 12/24시간 시계, JSON 백업·복원·초기화 |
| 시스템 정보 | 버전·제한·저장 위치 및 조작 도움말 |

모든 파일과 터미널 명령은 브라우저 안의 가상 데이터만 다룹니다. 명령은 허용 목록으로 처리하고 사용자 텍스트를 HTML로 실행하지 않습니다. 효과음은 포함하지 않았으며 음소거 설정값은 보관합니다. `About.txt`에는 숨겨진 명령의 힌트가 있습니다.

## 조작

- 데스크톱 아이콘: 두 번 클릭 또는 선택 후 `Enter`. 터치 화면에서는 한 번 누릅니다.
- 창: 제목줄 드래그, 가장자리·모서리 크기 조절, 최소화·최대화·복원·닫기. 최대화된 창은 복원한 후 이동합니다.
- 작업표시줄: 열린 창 버튼을 눌러 최소화하거나 복원합니다. 바탕화면 보기 버튼으로 모든 창을 최소화합니다.
- 시작 메뉴: 방향키·`Home`·`End`로 이동하고 `Enter`로 실행합니다. `Esc` 또는 빈 곳 클릭으로 닫습니다.
- 바탕화면 우클릭: 새 문서, 아이콘 자동 정렬, 새로고침, 설정. 큰 화면에서는 아이콘을 끌어 배치합니다.
- 메모장: `Ctrl/Cmd+S` 저장, `Ctrl/Cmd+Shift+S` 다른 이름으로 저장, `Ctrl/Cmd+Z` 실행 취소.
- 탐색기: `F2` 이름 변경, `Delete` 삭제, 방향키 선택, `Enter` 열기. 이동 메뉴에는 대상 가상 폴더 경로를 입력합니다.
- 그림판: 도구·색상·굵기를 선택해 마우스 또는 터치로 그립니다. `Ctrl/Cmd+Z`로 취소합니다. 크기 변경 시 그림은 보존하며 실행 취소 기록은 비웁니다.
- 지뢰찾기: 클릭으로 열기, 우클릭 또는 깃발 모드로 표시, 방향키 이동·`F` 깃발. 웃는 얼굴 버튼으로 다시 시작합니다.
- 터미널: `help` 도움말, 위·아래 방향키 입력 기록. 공백이 있는 경로는 따옴표로 감쌉니다.

작은 화면의 창은 전체 화면 형태로 열립니다. 대화상자는 `Esc`로 취소할 수 있습니다. 운영체제·브라우저가 예약한 단축키는 해당 환경의 동작이 우선할 수 있습니다.

## 저장·복구 및 제한

가상 파일, 저장한 문서, 설정, 바탕화면 아이콘 위치를 `localStorage`의 `retro-os-v1`에 스키마 버전 1 JSON으로 저장합니다. 자동 저장은 변경 후 700ms 지연하며 페이지를 벗어나거나 숨길 때도 저장을 시도합니다. 저장소가 차거나 차단되면 안내가 표시됩니다. 브라우저 데이터 삭제·비공개 모드 종료 등으로 저장 내용이 사라질 수 있으므로 필요한 데이터는 설정에서 JSON으로 내보내세요.

열린 창과 창의 위치·크기, 저장하지 않은 메모, 지뢰찾기 진행, 그림판 캔버스는 새로고침 후 복원하지 않습니다. 그림판은 PNG로 따로 저장합니다. 설정 변경 시 열린 창은 유지합니다. JSON 가져오기와 초기화는 현재 데이터를 바꾸고 열린 창을 닫으며, 미저장 작업이 있으면 확인을 받습니다. 잘못된 백업은 적용하지 않습니다.

| 항목 | 상한 |
| --- | --- |
| 파일·폴더 | 시스템 폴더 포함 600개, 깊이 8단계, 이름 80자 |
| 텍스트 파일 | UTF-8 기준 파일당 256KB |
| JSON 백업 | 2MB, 버전·구조·ID·경로·범위 검증 |
| 창 | 전체 12개, 탐색기 4개; 앱·같은 파일별 중복 실행 제한 |
| 터미널 | 출력 500줄, 입력 기록 100개, 명령 입력 4096자 |
| 그림판 | 가로 최대 640 논리 픽셀, DPR 최대 2, 실행 취소 8회 |

폴더 순환 이동, 이름 충돌, 잘못된 경로 및 위험한 JSON 속성은 거부합니다. 시계는 공유 타이머 1개를 사용하며 숨김 상태에서는 중지하고 복귀 시 현재 시간을 갱신합니다. 로딩 창이 보이는 동안 고양이·막대에 RAF 루프 1개를 공유합니다. 최소화·숨김·닫기 시 정지하고 설정의 애니메이션 끄기와 움직임 줄이기 설정을 따릅니다.

## 테스트

Node.js 내장 테스트 러너로 도메인 테스트를 실행합니다.

```sh
npm test
```

브라우저 검증 스크립트는 개발용 선택 도구입니다. 아래 Playwright 스크립트와 장시간 검사는 제공된 실행 경로이며, 이 명령의 작성 자체를 실행·통과 증거로 간주하지 않습니다. 실제 수행 범위와 미실행 항목은 `TEST_REPORT.md`를 확인하세요.

정적 서버를 실행한 상태에서 별도 터미널을 엽니다.

```sh
npm install --no-save playwright
npx playwright install chromium
BASE_URL=http://localhost:4173/ node tests/browser-e2e.mjs
```

```sh
BROWSER=firefox BASE_URL=http://localhost:4173/ node tests/browser-e2e.mjs
SOAK_MINUTES=60 BASE_URL=http://localhost:4173/ node tests/browser-e2e.mjs
```

다른 엔진은 먼저 `npx playwright install firefox` 또는 `webkit`으로 설치합니다. 결과는 `test-results/report.json`과 같은 폴더의 화면 이미지에 기록합니다. 스크립트는 새 브라우저 컨텍스트에서 외부 요청을 차단하고 저장·재방문, 창·그림판 반복 수명주기, 터미널 제한, JSON 파괴 입력, 화면 크기 변경, 8시간 시간 점프 모의 검사를 수행합니다. `SOAK_MINUTES=60`은 2분 예열 후 60분 동안 5분 간격으로 샘플링합니다. 실제 1·8시간 백그라운드, PC 절전, 실제 모바일 복귀 검사는 별도 수동 검증이 필요합니다. JS heap은 브라우저·GPU 전체 메모리를 의미하지 않습니다.

## GitHub Pages 배포

저장소에 이 프로젝트의 **내용 전체**를 올립니다. 저장소 루트에 `.github/`, `dist/`, `tests/`, `package.json`이 있어야 합니다. ZIP을 풀었을 때 생기는 `retro-os/` 폴더 안의 내용을 저장소 루트에 넣으세요. 숨김 폴더인 `.github`도 포함해야 합니다.

1. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. `main` 또는 `master` 브랜치에 푸시합니다. 다른 브랜치를 쓰면 `.github/workflows/pages.yml`의 `branches`를 바꿉니다.
3. **Actions → Deploy RETRO OS to GitHub Pages**가 성공하면 배포된 주소를 엽니다. **Run workflow**로 수동 실행할 수도 있습니다.

워크플로는 Node.js 24에서 테스트를 실행한 뒤 `dist/`만 Pages에 업로드합니다. 서버 코드·데이터베이스·환경변수·API 키·npm 패키지 설치는 필요하지 않습니다. 이미지·글꼴·스크립트는 로컬 상대 경로를 사용하며 `/repo-name/` 하위 경로에서도 작동합니다. `.nojekyll`도 포함했습니다. 실제 GitHub Actions 실행과 GitHub Pages 게시 자체는 아직 수행하지 않았습니다.

다른 정적 호스팅에는 `dist/`의 내용 전체를 공개 루트로 배포하세요. 브랜치 기반 Pages를 사용한다면 `dist/` 내용만 해당 브랜치 루트에 복사합니다. GitHub Pages는 정적 화면을 제공하며, 실제 Mac 제어는 아래 로컬 실행기로 사용합니다.

## 파일 구성·출처

- `dist/index.html`, `dist/styles/`: 화면과 스타일
- `dist/src/main.js`: 데스크톱·시작 메뉴·공유 서비스
- `dist/src/window-manager.js`, `input.js`, `render.js`: 창 관리·포인터·아이콘
- `dist/src/state.js`, `storage.js`: 가상 파일 시스템·검증·저장
- `dist/src/apps-text.js`, `apps-extra.js`: 내장 프로그램과 지뢰찾기 모델
- `tests/`: Node 테스트와 선택 브라우저 검증 스크립트

GUI와 작은 도구 모음 기호는 프로젝트에서 작성했습니다. 앱 아이콘은 [SaurezH의 Retro Desktop Icons](https://saurezh.itch.io/rdi) 원본 아틀라스를 사용합니다. 제작자는 무료 상업·비상업 프로젝트 내 사용을 허용하며, 에셋만 별도로 재배포·판매하는 것은 금지합니다. 지뢰찾기 아이콘은 [Haiku 아이콘](https://www.haiku-inc.org/trademarks/haiku_icons/)이며 MIT 라이선스입니다. 고양이는 [LuizMelo의 Pet Cats Pack](https://luizmelo.itch.io/pet-cat-pack), CC0 원본 프레임을 사용합니다. 자세한 출처와 동봉 라이선스 위치는 `THIRD_PARTY_NOTICES.md`에 기록했습니다.

CSS 프레임워크는 사용하지 않습니다. 한글 글꼴은 [Neo둥근모 공식 프로젝트](https://github.com/neodgm/neodgm)의 NeoDunggeunmo이며 [공식 웹폰트 키트](https://github.com/neodgm/neodgm-webfont)를 참고합니다. Eunbin Jeong (Dalgona.)의 저작권 표기 및 SIL Open Font License 1.1 전문을 `dist/assets/fonts/LICENSE.txt`에 동봉했습니다. 모든 이미지와 WOFF2 파일은 로컬에서 제공하며 실행 중 원격 에셋을 요청하지 않습니다.

## 실제 Mac 연결 (추가 기능)

웹에서 호스팅하는 정적 버전과 Mac에서 실행하는 로컬 버전은 같은 화면을 사용합니다. **실제 앱·시스템 제어는 Mac용 로컬 실행기로 열었을 때만 작동합니다.** 공개/비공개 호스팅 사이트가 Mac을 원격 제어하지 않습니다.

1. `retro-os-mac.zip`을 풀고 `RETRO OS.command`를 두 번 클릭합니다.
2. `http://127.0.0.1:4188`에서 RETRO OS가 열립니다. Node.js 20 이상이 필요하며 외부 npm 패키지는 없습니다.
3. 바탕화면 **내 컴퓨터**를 엽니다. 터미널 창을 종료하거나 Ctrl+C를 누르면 연결이 종료됩니다.

명령줄에서는 `node companion/server.mjs`로 시작합니다. `--no-open` 옵션은 기본 브라우저를 자동 실행하지 않습니다. 이미 실행 중이면 같은 로컬 화면을 엽니다.

- 프로그램: Finder, 텍스트 편집기, 계산기, 메모, Safari, 터미널, 시스템 설정을 실제로 실행합니다.
- 파일: **폴더 연결** 또는 **파일 열기**에서 사용자가 고른 항목만 다룹니다. UTF-8 텍스트 파일을 최대 1MB까지 편집·저장하며, 덮어쓰기 전에 확인합니다. 다른 앱이 파일을 변경하면 저장을 중단합니다. 새 파일은 **다른 이름으로 저장**에서 위치를 선택합니다.
- 제어판: Mac 출력 음량·음소거, 라이트/다크 모드를 조작합니다. macOS가 자동화 권한을 요청하면 사용자가 직접 결정합니다.
- 가상 디스크 **R:**와 실제 PC 파일은 별개입니다. PC 문서 내용과 선택한 경로는 가상 파일 백업·localStorage·외부 서버에 저장하지 않습니다. 실제 파일 삭제·셸 명령·전원 끄기 기능은 제공하지 않습니다.
- 로컬 실행기는 127.0.0.1에만 바인딩하고 시작마다 토큰을 새로 만듭니다. 같은 출처의 요청만 받고 CORS를 허용하지 않으며, 실행 가능한 앱과 시스템 동작을 명시적으로 제한합니다. 선택 폴더 밖 경로와 심볼릭 링크 우회는 차단합니다.

호스팅 버전의 **내 컴퓨터**에서는 실행기를 내려받을 수 있습니다. macOS 외 플랫폼의 실제 시스템 제어는 지원하지 않습니다.

## 로딩 창과 고양이

로딩 막대는 실제 PC 작업을 나타내지 않는 데스크톱 애니메이션이며 90초 주기로 천천히 반복합니다. 고양이는 46초 주기로 좌우 달리기·그루밍·앉기·잠자기·기지개를 반복합니다. 이동 시작과 끝은 부드럽게 감속·가속하며 모든 프레임의 발높이를 제목줄에 고정합니다. 클릭/Enter/Space로 놀아주고, 우클릭하면 흰색·회색·주황·검정 고양이로 바꿉니다. 잠든 고양이를 누르면 기지개를 켜고 반응합니다. 취소 또는 닫기는 창과 애니메이션을 종료합니다. 시작 → 설정 → 로딩 창 또는 바탕화면 우클릭 → 로딩 창에서 다시 표시합니다.

바탕화면 아이콘은 기본적으로 화면 높이에 맞춰 자동 정렬되며, 좁은 화면에서는 가로로 줄 바꿈합니다. 빈 바탕화면을 드래그하면 영역 안의 아이콘을 선택합니다. Ctrl/Cmd+A로 전체 선택하고 Ctrl/Cmd+클릭으로 선택을 더하거나 뺍니다. 자동 정렬은 바탕화면 우클릭 메뉴에서 켜고 끕니다. 끄면 선택한 아이콘들을 함께 끌어 배치할 수 있습니다. 달리는 고양이는 위아래로 뛰지 않고 제목줄 위에서 좌우로만 이동합니다.
